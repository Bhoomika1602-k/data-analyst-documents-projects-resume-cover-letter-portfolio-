Project Title

Web Data Collection for Data Analytics

Objective

The objective of this project is to collect structured data from public websites and convert unstructured HTML content into a clean dataset suitable for data analysis.

Data Source

Publicly available website:
https://books.toscrape.com

Tools & Technologies Used

Python

BeautifulSoup

Requests

Pandas

VS Code

Methodology

Identified relevant data fields from the website

Analyzed HTML structure using browser inspect tools

Extracted data using BeautifulSoup

Stored extracted data in lists

Converted data into a structured Pandas DataFrame

Exported the final dataset as a CSV file

Validated data for missing and duplicate values

Dataset Description

The dataset contains the following columns:

Title

Price

Availability

Output

CSV file (books_dataset.csv) ready for analysis and visualization

Ethical Considerations

Only public data was scraped

No personal or private data was collected

Website scraping rules were respected

Future Scope

Handle multiple pages (pagination)

Scrape dynamic websites

Store data in databases

Perform advanced analysis and visualization
