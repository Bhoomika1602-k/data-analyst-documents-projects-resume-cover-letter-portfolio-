# Focus Drift Detector (Machine Learning)

This project predicts a student's focus level using typing behavior data.

## Features Used
- Typing Speed
- Pause Count
- Backspace Count
- Average Key Delay

## Model
- Random Forest Classifier
- Behavioral Machine Learning

## Focus Labels
0 - Focused  
1 - Slightly Distracted  
2 - Highly Distracted  

## Tools
- Python
- Pandas
- Scikit-learn
- VS Code

## Use Case
Helps detect attention drift during study sessions without using cameras or sensors.
